# Twinkle Tray Offline Custom

Личная офлайн-версия Twinkle Tray для Windows x64.

## Изменения

- Компактные кнопки пресетов яркости под ползунками, подсветка текущих значений.
- Создание, переименование, изменение значений и удаление пресетов в разделе «Настройки → Пресеты».
- Удалены реализации телеметрии, обновлений и запроса геолокации.
- HTTP, DNS, TCP, UDP и WebSocket блокируются в основном процессе, процессах мониторов и интерфейсе.
- Встроенный браузер разрешает локальные ресурсы и отменяет сетевые запросы.
- Настройки не могут повторно включить телеметрию, обновления или UDP-сервер.

## Сборка

Требуются Windows, Node.js и Visual Studio с инструментами C++. При установке зависимостей нужны интернет и заголовки Electron; готовое приложение работает офлайн.

```powershell
npm ci
npm run parcel-build
node node_modules/electron-builder/cli.js --win --x64 --dir --config electron-builder.custom.cjs
```

Готовая папка: `../Twinkle-Tray-Portable/win-unpacked`. Запуск: `Twinkle Tray Custom.exe`.
Настройки и пресеты хранятся в `data` рядом с приложением. Перед повторной упаковкой сохраняйте эту папку отдельно: electron-builder очищает каталог сборки.

Проверки:

```powershell
node --test tests/quick-presets.test.js tests/quick-presets-ipc.test.js tests/preset-ui.test.js tests/offline.test.js
```

13 проверок покрывают пресеты, интерфейс, обработчики настроек, сетевую блокировку и сохранение локальной связи через именованные каналы Windows.
